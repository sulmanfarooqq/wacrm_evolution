# wacrm_evolution

Combination of **wacrm** (a Next.js 16 + Supabase WhatsApp CRM) and the
**Evolution API** — the app is migrated from the Meta WhatsApp Cloud API to a
self-hosted Evolution API instance, with a Gemini-powered AI auto-reply
assistant.

- `wacrm/` — the application (source, Supabase migrations, tests)
- `docs/` — migration work log and setup / go-live runbook

Start here: [`docs/setup-runbook.md`](docs/setup-runbook.md)

**Live deployment:** https://wacrm-evolution.vercel.app — Vercel setup and
step-by-step deploy: [`wacrm/DEPLOY_VERCEL.md`](wacrm/DEPLOY_VERCEL.md)
